プライバシーポリシー

運営者：LPP GAME LAB（以下「当サイト」）

1. 集める情報

当サイトのゲーム「キシドラ！」は、名前やメールアドレスなどの登録なしで遊べます。遊ぶときに、次の情報を扱います。

  • ブラウザの中に残る記録：ゲームの進み具合と設定です。あなたのブラウザの中に保存します
  • フレンド機能で送る情報：ゲームの中で付けたプレイヤー名、ゲームが自動で作るプレイヤー番号と合言葉（元に戻せない形で保存します）、持っている装備、進み具合、最後に遊んだ日時、フレンドの関係、引き継ぎコードの内容です
  • Google ログイン（使う人だけ）：記録を Google アカウントに預ける機能を使うと、Google から受け取ったアカウントの番号だけを、プレイヤー番号と結びつけて保存します。メールアドレス・名前・写真は保存しません。連携はゲームの「引き継ぎ」の画面でいつでも解除できます
  • IP アドレス：登録のしすぎや不正を防ぐために、元に戻せない形に変えて使います
  • お問い合わせ：メールをいただいたときの、メールアドレスと本文です

2. 使いみち

  • フレンド機能、武器のレンタル、ランキング、引き継ぎなどの機能を動かすため
  • 不正なデータや迷惑な使い方を見つけて、止めるため
  • お問い合わせに答えるため

法律にもとづく場合をのぞいて、集めた情報を、あなたの同意なく第三者に渡すことはありません。

3. 外部のサービス

当サイトのページは GitHub Pages で配信しています。ゲームのサーバーには Cloudflare を使っています。Google ログインを使うときは、Google の公式のログインの部品（Google Identity Services）を読み込みます。これらのサービスは、配信のために IP アドレスなどの接続情報を扱うことがあります。

4. 広告について

当サイトでは、Google AdSense などの第三者配信の広告サービスを利用することがあります。Google などの第三者配信事業者は、Cookie を使って、あなたが当サイトや他のサイトを訪れた情報にもとづいて広告を配信します。

Google が広告 Cookie をどう使うかは、Google の広告に関するポリシーで確かめられます。パーソナライズ広告は、Google の広告設定で無効にできます。第三者配信事業者の Cookie は、aboutads.info で無効にできます。

ゲームの中で動画広告を見ると報酬がもらえる機能を入れた場合も、広告を見るかどうかはあなたが選べます。

5. 情報の削除

ブラウザの記録は、ゲームの中の「データの初期化」で消せます。サーバーの情報の削除は、下のお問い合わせ先にご連絡ください。ご本人の確認のため、プレイヤー番号をお知らせいただきます。

内容は、必要に応じて変更することがあります。変更したときは、このページでお知らせします。
