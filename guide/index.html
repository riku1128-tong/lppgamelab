キシドラ！の遊び方

戦いの流れ

戦いはターン制です。敵のそばの数字は、攻撃までの残りターンです。0 になると、その敵が攻撃してきます。

こちらの番では、持っている武器のスキルを選んで攻撃します。スキルには ST（スタミナ）を使います。足りないとスキルが出せないので、うまくガードして取りもどしながら戦いましょう。

STAGE は何度かの WAVE でできています。敵を全部たおすと次の WAVE に進み、最後の WAVE を突破するとクリアです。宝箱の中身やコインは、クリアしたあとに手に入ります。

ガードのコツ

敵が攻撃してくる瞬間にガードのボタンを押します。押すタイミングで、結果が変わります。

  • ガード：受けるダメージを減らします。減る量は盾の DEF で決まります
  • ジャストガード：ぎりぎりで押すと、ダメージが大きく減り、ST が少し回復します
  • ミラクルガード：いちばん難しいタイミングです。ダメージをなくして、HP を回復し、ST も満タンになります

早く押しすぎると間に合わないので、攻撃の合図をよく見てから押しましょう。難易度を下げると、タイミングの幅が広がります。

武器とスキル

武器は剣・槍・槌の 3 種類で、メインとサブの 2 本を持って戦えます。敵には弱い武器の種類があり、弱点をつくとダメージが増え、敵をスタンさせやすくなります。

決まった順番でスキルをつなげると、必殺技が出ます。スタンした敵は動けなくなるので、必殺技を当てる大きなチャンスです。装備の画面で、その組み合わせで出せる必殺技を確かめられます。

装備を育てる

  • ショップ：コインでガチャを引いて、武器や盾を集めます
  • 鍛冶屋の強化：強化鉄を使って、武器や盾の力を上げます
  • 鍛冶屋の進化：素材を集めると、ひとつ上のレア度の装備に進化させられます
  • フレンド：フレンドの武器を借りて、いっしょに戦えます

勝てない STAGE があったら、敵の弱点を調べて武器を替えるのが近道です。敵を長押しすると、弱点を確かめられます。

セーブについて

記録は、遊んでいるブラウザの中に残ります。ブラウザのデータを消すと記録も消えるので、機種を変えるときなどは、ゲームの中の「引き継ぎコード」を使ってください。
